# Εργασία Αλγορίθμων 2026

Αυτό το αποθετήριο περιέχει τις λύσεις για την εξαμηνιαία εργασία στο μάθημα "Αλγόριθμοι" (2026).

## Δομή Αποθετηρίου

Η εργασία είναι χωρισμένη σε δύο κύρια μέρη, το καθένα στον δικό του φάκελο:

* **assignment-2026-1/**: Περιέχει την υλοποίηση για το πρόβλημα των κερμάτων του Frobenius (McNuggets / Perplexity).
* **assignment-2026-2/**: Περιέχει την υλοποίηση για το πρόβλημα της συνάντησης δύο οντοτήτων σε γράφο (Rendezvous).

## Περιγραφή Παραδοτέων

### 1. Perplexity (Frobenius Coin Problem)
Ο κώδικας υπολογίζει τον μεγαλύτερο ακέραιο αριθμό που δεν μπορεί να εκφραστεί ως γραμμικός συνδυασμός μιας δοθείσας σειράς θετικών ακεραίων (αριθμός Frobenius).
* **Αρχείο:** `assignment-2026-1/perplexity.py`
* **Τρόπος εκτέλεσης:** ```bash
    python assignment-2026-1/perplexity.py [αριθμοί...]
    ```

### 2. Rendezvous (Meeting in a Graph)
Ο κώδικας βρίσκει τη συντομότερη διαδρομή για να συναντηθούν δύο οντότητες (Alice και Bob) που κινούνται ταυτόχρονα σε έναν γράφο. 
* **Χαρακτηριστικά:** * Χρήση αλγορίθμου BFS για την εύρεση της βέλτιστης συνάντησης.
    * Αυτόματη αναγνώριση διμερών (bipartite) γράφων.
    * Προσθήκη ελάχιστης ακμής σε περίπτωση που η συνάντηση είναι αδύνατη λόγω διμέρειας.
* **Αρχείο:** `assignment-2026-2/rendezvous.py`
* **Τρόπος εκτέλεσης:** ```bash
    python assignment-2026-2/rendezvous.py [όνομα_αρχείου_γράφου]
    ```
