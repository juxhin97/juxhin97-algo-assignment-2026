# Εργασία Αλγορίθμων 2026

Αυτό το αποθετήριο περιέχει τις λύσεις για την εξαμηνιαία εργασία στο μάθημα "Αλγόριθμοι" (2026).

## Δομή Αποθετηρίου

Η εργασία είναι χωρισμένη σε τρία κύρια μέρη, το καθένα στον δικό του φάκελο:

* **assignment-2026-1/**: Περιέχει την υλοποίηση για το πρόβλημα Perplexity.
* **assignment-2026-2/**: Περιέχει την υλοποίηση για το πρόβλημα Rendezvous.
* **assignment-2026-3/**: Περιέχει την υλοποίηση για το πρόβλημα MathSticks.

## Περιγραφή Παραδοτέων

### 1. Perplexity (Language Modeling)
Ο κώδικας υπολογίζει το Perplexity ενός αρχείου κειμένου χρησιμοποιώντας το προεκπαιδευμένο μοντέλο γλώσσας GPT-2. Η υλοποίηση χρησιμοποιεί την τεχνική του "ολισθαίνοντος παραθύρου" (sliding window) για τη διαχείριση μεγάλων κειμένων και τον ορθό υπολογισμό της πιθανότητας των tokens.
* **Αρχείο:** `assignment-2026-1/perplexity.py`
* **Τρόπος εκτέλεσης:** ```bash
    python assignment-2026-1/perplexity.py --n-ctx 2048 --stride 512 input.txt output.out
    ```
* **Παράμετροι:**
    * `--n-ctx`: Το μέγεθος του παραθύρου συμφραζομένων (default 2048).
    * `--stride`: Το βήμα μετατόπισης του παραθύρου (default 512).
    * `input_file`: Το αρχείο κειμένου προς ανάλυση.
    * `output_file`: Το αρχείο όπου θα αποθηκευτεί το τελικό αποτέλεσμα.

### 2. Το Πρόβλημα της Συνάντησης (Rendezvous)
Στον φάκελο `assignment-2026-2`, εξετάζουμε πώς δύο οντότητες μπορούν να συναντηθούν στον ίδιο κόμβο ενός γράφου στον ελάχιστο χρόνο. 
* **Η ιδιαιτερότητα:** Ο αλγόριθμος χρησιμοποιεί Breadth-First Search (BFS) και έχει τη δυνατότητα να "διορθώνει" διμερείς γράφους προσθέτοντας μια ακμή, ώστε η συνάντηση να είναι πάντα εφικτή.
* **Πώς τρέχει:** `python assignment-2026-2/rendezvous.py graph_10.txt`.

### 3. Γρίφοι με Σπίρτα (MathSticks Solver)
Στον φάκελο `assignment-2026-3`, υλοποιούμε έναν αλγόριθμο που λύνει αριθμητικούς γρίφους με σπίρτα μετακινώντας το πολύ k σπίρτα, ώστε να διορθωθεί μια λανθασμένη εξίσωση.
* **Η ιδιαιτερότητα:** Ο αλγόριθμος χρησιμοποιεί Αναζήτηση κατά Βάθος (DFS) με Look-Ahead Pruning, ελέγχοντας αν οι κινήσεις ξεπερνούν το όριο *πριν* την αναδρομική επίσκεψη των κόμβων, μειώνοντας δραστικά τον χώρο αναζήτησης. Η έξοδος τυπώνεται σε μορφή JSON με τις κινήσεις ταξινομημένες βάσει της μεθόδου Sort-and-Zip.
* **Πώς τρέχει:** `python assignment-2026-3/mathstick.py --problem "0+0=1" --max-k 2`.
