# Εργασία Αλγορίθμων 2026

Αυτό το αποθετήριο περιέχει τις λύσεις για την εξαμηνιαία εργασία στο μάθημα "Αλγόριθμοι" (2026).

## Δομή Αποθετηρίου

Η εργασία είναι χωρισμένη σε δύο κύρια μέρη, το καθένα στον δικό του φάκελο:

* **assignment-2026-1/**: Περιέχει την υλοποίηση για το πρόβλημα Perplexity.
* **assignment-2026-2/**: Περιέχει την υλοποίηση για το πρόβλημα Rendezvous.

## Περιγραφή Παραδοτέων

### 1. Επίλυση του Προβλήματος Frobenius (Perplexity)
Στον φάκελο `assignment-2026-1`, θα βρείτε την προσέγγισή μου για τον υπολογισμό του προβλήματος Perplexity. Το πρόγραμμα αναζητά τον μεγαλύτερο αριθμό που δεν μπορεί να σχηματιστεί ως συνδυασμός κερμάτων συγκεκριμένης αξίας.
* **Πώς τρέχει:** Δίνουμε τις αξίες των κερμάτων ως ορίσματα, π.χ. `python assignment-2026-1/perplexity.py 5 24`.
