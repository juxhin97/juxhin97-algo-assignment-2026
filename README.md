# Εργασία Αλγορίθμων 2026

Αυτό το αποθετήριο περιέχει τις λύσεις για την εξαμηνιαία εργασία στο μάθημα "Αλγόριθμοι" (2026).

## Δομή Αποθετηρίου

Η εργασία είναι χωρισμένη σε δύο κύρια μέρη, το καθένα στον δικό του φάκελο:

* **assignment-2026-1/**: Περιέχει την υλοποίηση για το πρόβλημα των κερμάτων του Frobenius (McNuggets / Perplexity).
* **assignment-2026-2/**: Περιέχει την υλοποίηση για το πρόβλημα της συνάντησης δύο οντοτήτων σε γράφο (Rendezvous).

## Περιγραφή Παραδοτέων

### 1. Επίλυση του Προβλήματος Frobenius (Perplexity)
Στον φάκελο `assignment-2026-1`, θα βρείτε την προσέγγισή μου για τον υπολογισμό του αριθμού Frobenius. Το πρόγραμμα αναζητά τον μεγαλύτερο αριθμό που δεν μπορεί να σχηματιστεί ως συνδυασμός κερμάτων συγκεκριμένης αξίας.
* **Πώς τρέχει:** Δίνουμε τις αξίες των κερμάτων ως ορίσματα, π.χ. `python assignment-2026-1/perplexity.py 5 24`.

### 2. Το Πρόβλημα της Συνάντησης (Rendezvous)
Στον φάκελο `assignment-2026-2`, εξετάζουμε πώς δύο οντότητες μπορούν να συναντηθούν στον ίδιο κόμβο ενός γράφου στον ελάχιστο χρόνο. 
* **Η ιδιαιτερότητα:** Ο αλγόριθμος χρησιμοποιεί Breadth-First Search (BFS) και έχει τη δυνατότητα να "διορθώνει" διμερείς γράφους προσθέτοντας μια ακμή, ώστε η συνάντηση να είναι πάντα εφικτή.
* **Πώς τρέχει:** `python assignment-2026-2/rendezvous.py graph_10.txt`.
